## รายละเอียดโปรแกรม
FlowBudget เป็นแอปพลิเคชัน Desktop พัฒนาด้วยภาษา Python โดยใช้ไลบรารี CustomTkinter ในการทำหน้าต่างโปรแกรม ช่วยให้บันทึกรายรับและรายจ่ายในแต่ละวันได้สะดวก เก็บข้อมูลลงฐานข้อมูล SQLite ในเครื่อง และสรุปผลเป็นกราฟสถิติเพื่อช่วยวางแผนการเงิน

### ฟังก์ชันการทำงาน
- บันทึกรายการรายรับ-รายจ่าย ระบุหมวดหมู่ ช่องทางชำระเงิน และโน้ตบันทึกช่วยจำ
- มีระบบดักจับข้อมูลผิดพลาด (Validation) เช่น ป้องกันการกรอกจำนวนเงินติดลบ
- ค้นหาประวัติย้อนหลังตามคำค้น หรือเลือกกรองเฉพาะรายรับ/รายจ่าย
- สรุปยอดเงินคงเหลือรวม รายรับ-รายจ่ายประจำเดือน และคำนวณอัตราการออม
- แสดงกราฟสัดส่วนค่าใช้จ่าย (Donut Chart) และกราฟแท่งแนวโน้มรายเดือน โดยใช้ Matplotlib
- ตั้งเพดานงบประมาณรายหมวดหมู่ พร้อมแถบสีแจ้งเตือนเมื่อใช้เงินใกล้เต็มหรือเกินงบ
- ส่งออกประวัติรายการทั้งหมดเป็นไฟล์ CSV สำหรับเปิดดูใน Excel
- รองรับการสลับโหมด Dark Mode และ Light Mode

## ไลบรารีที่ใช้ในการพัฒนา
- `customtkinter` (สำหรับทำ UI หน้าต่างโปรแกรม)
- `matplotlib` (สำหรับวาดกราฟสถิติ)
- `pillow` (สำหรับจัดการรูปภาพและไอคอน)
- `sqlite3` (ฐานข้อมูลในตัวของ Python)

---

## ขั้นตอนการติดตั้งและรันโปรแกรม

1. ติดตั้งไลบรารีที่จำเป็น:
```bash
pip install customtkinter matplotlib pillow
```

2. สั่งรันโปรแกรม:
```bash
python main.py
```
